# Лабораторная работа №6 (C++)

Репозиторий содержит решения заданий 1-6 по работе с коллекциями (списками, векторами, кортежами) на языке C++ (стандарт C++17).

## Список заданий:

*   **Задание 1:** Работа со списком (сумма, среднее, минимум, максимум, сортировка, удаление дубликатов с сохранением порядка).
*   **Задание 2:** Поиск дубликатов в списке (двумя способами: через `std::map` и через `std::set`).
*   **Задание 3:** Транспонирование матрицы (создание двумерного вектора).
*   **Задание 4:** Работа с кортежами (`std::tuple`). Поиск самого старшего студента, студента с лучшим баллом, вычисление среднего возраста и сортировка.
*   **Задание 5:** Объединение, пересечение и разность списков`.
*   **Задание 6:** Проверка списка на отсортированность (по возрастанию и убыванию).

## Требования для сборки
*   Компилятор с поддержкой **C++17** (например, `g++`, `clang++` или MSVC).

Каждый файл (`zad1.cpp`, `zad2.cpp` и т.д.) можно скомпилировать и запустить отдельно.
